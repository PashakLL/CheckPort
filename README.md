# CheckPort

Консольная утилита на Python для проверки TCP-портов по списку хостов. Только стандартная библиотека.

## Запуск

Нужен Python 3.10+ (проверялось на 3.14, macOS).

```
python3 port_checker.py
```

## Список проверок

Файл `targets.txt` рядом со скриптом, одна проверка на строку в формате `host:port`:

```
google.com:443
localhost:9999
192.0.2.1:80
nonexistent.invalid:443
localhost:abc
```

Некорректные строки (пустые, без порта, с нечисловым портом) пропускаются.

## Пример вывода

```
Строка пропущена: 'localhost:abc'
1. google.com:443 - Успешное подключение
2. localhost:9999 - Порт закрыт
3. 192.0.2.1:80 - Таймаут превышен
4. nonexistent.invalid:443 - Имя хоста не найдено
```

## Статусы

| Статус | Значение |
|---|---|
| Успешное подключение | порт принял соединение |
| Порт закрыт | хост ответил отказом, на порту никто не слушает |
| Таймаут превышен | нет ответа за 2 секунды (файрвол, хост выключен или недоступен) |
| Имя хоста не найдено | не удалось получить IP по имени |
| Сетевая ошибка | другая сетевая проблема, например нет маршрута |

## Проверка интернета

Перед основными проверками программа подключается к `1.1.1.1:443` и `8.8.8.8:443` (по IP, без DNS). Если не ответил ни один, выводится предупреждение. Это эвристика: если сеть блокирует эти адреса, предупреждение может быть ложным.

## Результаты

Каждый запуск дописывает дату и результаты в `results.txt` (файл в `.gitignore`, появится автоматически при первом запуске).

## Ограничения

- «Успешное подключение» означает только установленное TCP-соединение, а не работающую службу. Например, при тестировании `google.com:81` с включённым VPN был успех, а без VPN таймаут: вероятно, соединение принимал промежуточный узел (это предположение, не проверенный факт). Также порт может принимать соединения, пока служба зависла или отвечает ошибкой.
- Без сети проверки по имени могут показывать «Имя хоста не найдено».
- Таймаут действует на каждый адрес хоста отдельно, поэтому ожидание может быть дольше 2 секунд.
- Проверки идут последовательно.

Проверяйте только свои хосты и публичные сервисы.
