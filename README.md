# CheckPort

Консольная утилита на Python для проверки доступности TCP-портов по списку хостов. Использует только стандартную библиотеку.

## Запуск

```
python3 port_checker.py
```

Python 3 (проверялось на Python 3.14, macOS). Только стандартная библиотека, ничего устанавливать не нужно.

## Список проверок

Файл `targets.txt` лежит рядом со скриптом, одна проверка на строку в формате `host:port`:

```
google.com:443
localhost:22
192.0.2.1:80
```

Некорректные строки (пустые, без порта, с нечисловым портом) пропускаются с сообщением.

## Статусы

- Успешное подключение: порт принял соединение
- Порт закрыт: хост ответил отказом
- Таймаут превышен: ответа нет за 2 секунды (так бывает при блокировке файрволом или недоступном хосте)
- Имя хоста не найдено: ошибка разрешения имени

Успешное подключение означает только, что порт принимает соединения, а не что служба работает корректно.

## Результаты

Каждый запуск дописывает в `results.txt` дату и результаты проверок. Файл в репозиторий не попадает.

Проверяйте только свои хосты и публичные сервисы.
